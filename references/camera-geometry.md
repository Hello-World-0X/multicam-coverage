# 机位几何 — 轴线、三角机位法、方位描述

## 1. 轴线（180° 规则）—— 第一铁律

两人对话时，**A、B 连线就是轴线**（axis）。摄影机只能在轴线的**同一侧**移动。

```
        A ←——————————→ B      ← 轴线（连接两人的视线线）

   ┌─────────────────────────────┐
   │   ✅ 机位区（轴线一侧）      │   M1 M2 M3 全部放这边
   └─────────────────────────────┘
   ═══════════════════════════════   ← 轴线
   ┌─────────────────────────────┐
   │   ❌ 禁区（轴线另一侧）      │   除非明确要「越轴镜头」
   └─────────────────────────────┘
```

**为什么违反就怪**：越轴后 A、B 的屏幕左右位置瞬间翻转，观众以为人物瞬移了。
生成图里的典型症状——「正反打里 A 在左，多机位图里 A 跑到右边」，90% 是模型
把机位放到轴线另一侧去了。

**在提示词里的写法**：
> 所有机位保持在人物 A-B 连线的同一侧（A 的左后方一侧）。画面中 A 始终位于
> 画面左半部、面朝右；B 始终位于画面右半部、面朝左。禁止左右翻转。

**实证补充**：越轴损害的是观众的**空间表征与物体位置记忆**（叙事理解不受影响）
——所以违例图「说不出哪里怪但就是不对」。自检清单 A 组永远第一优先。
（依据见 research-notes.md §1）

**合法越轴**（用户明确要越轴机位时按此交付，不要只给孤立的越轴图）：

1. **弧形移机**：一个连续镜头内摄影机绕过轴线；静态图序列为小角度递进模拟
2. **缓冲镜**：插入一个沿轴线的正侧镜头（90° 临界位）作为过渡
3. **重建定位**：先给总机位（M3）重新交代空间，再在新一侧出机位

## 2. 三角机位法（对话戏默认排布）

正反打的完整覆盖不是随便两个角度，是**三角形的三个顶点**：

```
                 M3（顶角·总机位）
                ╱  中景/全景·双人同框
               ╱   平视或略高
              ╱
    A ●——————————————● B
      M1 正打          M2 反打
      （过 A 肩拍 B）  （过 B 肩拍 A）
      或 A 单人中近景   或 B 单人中近景
```

- **M1 / M2（底边两端）**：正反打本身，互为反打。通常是过肩（OTS）或单人中近景。
  两机位到轴线的**距离和高度要接近**，焦距相同，景别对称。
  **OTS 的标准结构是三层深度**：前景（对方肩+后脑，虚化）→ 中景（对方面孔，
  合焦主体）→ 背景（虚化）。画面式描述按这个顺序写。
- **M3（顶角）**：总机位（master），双人同框交代空间关系。比 M1/M2 略高略远。

**30° 规则**（新增约束，来源见 research-notes.md §1）：同一主体的相邻机位
夹角必须 **≥30°**，或景别显著不同（跳两档），否则成组看像「同镜位抽了两张卡」
（跳剪感）。用户要的两个机位若夹角过近，建议改其中一个景别。

**批量补机位时的标准答案**（按需取用，不要凭空发明）：

| 机位 | 名称 | 位置 | 典型景别 | 用途 |
|---|---|---|---|---|
| M1 | 正打 | A 的后侧方，过 A 肩 | 中近景 | 说话人 A |
| M2 | 反打 | B 的后侧方，过 B 肩 | 中近景 | 说话人 B |
| M3 | 总机位 | 三角形顶角，双人同框 | 中景/全景 | 交代空间 |
| M4 | A 侧面 | 轴线一侧，A 的正侧面 | 中景 | 反应/侧写 |
| M5 | B 侧面 | 同侧，B 的正侧面 | 中景 | 反应/侧写 |
| M6 | 高角度 | 同侧上方 30–45° | 全景 | 俯瞰调度 |
| M7 | 特写 | 沿轴线同侧推近 | 特写/大特写 | 情绪强调 |

**同侧约束**：M4–M7 也必须和 M1/M2 在轴线同一侧。侧面机位（M4/M5）其实是
贴着轴线放的临界位，稍一偏就容易被模型放成越轴——提示词里要显式锁左右。

## 3. 机位方位描述规范（怎么把机位说清楚）

每个机位必须说满四件事，缺一不可：

1. **相对谁**：以人物/轴线为参照系（不是「画面左边」这种结果描述）
2. **方位角**：用钟面或度数（「B 的右前方 45°」「A 的正后方」）
3. **高度**：与人体部位对齐或给出米数（「胸口高度约 1.3m」「略高于头顶」）
4. **焦距 + 景别**（见焦距对照表）

**推荐句式**：
> 机位位于【参照】的【方向】【角度】，高度约【X m / 身体部位】，
> 焦距【X mm】，【过某人肩 / 无前景】，景别【X】，【参照人物】占画面【位置】。

**错误示范 → 正确示范**：
- ✗「换个俯视角度」→ ✓「机位在 B 右前方 45°、高度 2.2m 俯拍 30°，双人同框，焦距 28mm」
- ✗「特写 A 的脸」→ ✓「沿轴线同侧推近至 A 面前 1.2m，高度与眼齐平，85mm，A 面部占画面 70%，A 视线朝画面右方（B 的方向）」

## 4. 视线与屏幕方向锁定

多机位图里最容易崩的是**视线方向**。规则：

- 屏幕方向（screen direction）在所有同侧机位里**保持一致**：A 看右、B 看左
  （以正反打图为准），换机位后**不许对调**。
- 侧面机位里人物视线应指向**轴线上对方所在的一侧**。
- 特写里人物视线方向与他在中景里一致。

**匹配特写的正式规范**（Eyeline match 条目，来源见 research-notes.md §1）：
两个演员的匹配特写应满足——**相同焦距 + 相同机位高度 + 相同距离**，
画外演员位于镜头**等距的相反两侧**（A 看画外右，则 B 看画外左）。
这解释了正反打两镜「参数对称」的硬性要求：反推时两张图机位高度/焦距
不一致 = 素材本身不规范，报告用户裁决。

**提示词写法**（每张都带）：
> 屏幕方向锁定：A 面朝画面右侧并看向画面右外，B 面朝画面左侧并看向画面左外。
> 任何机位下不得翻转此朝向关系。

## 5. 焦距一致性（几何问题，不是风格）

同一场戏多机位，**焦距变化要小且要有意**。对话戏默认同一焦距（通常 32–50mm）。

实测 FOV（35mm 全画幅，公式 α = 2·arctan(d/2f)，详见 research-notes.md §4）：

| 焦距 | 对角 FOV | 水平 FOV | 透视效果 | 何时用 |
|---|---|---|---|---|
| 16mm | 107° | 95° | 强畸变，近大远小夸张 | 空间强调、压迫感；慎用于人脸 |
| 24mm | 84° | 74° | 明显广角 | 大全景、狭小空间 |
| 35mm | 63° | 54° | 轻微畸变，环境交代多 | 总机位、过肩的常规选择 |
| 50mm | 47° | 40° | 接近人眼，畸变小 | 单人中近景、正反打 |
| 85mm | 29° | 24° | 背景压缩、微虚化 | 特写、情绪镜头 |
| 200mm | 12° | 10° | 强压缩、极浅景深 | 意图性很强的特写；同一场戏别和广角混 |

**关键耦合**：保持主体占画面不变而换焦距 = 同时改变机位距离，
前景/主体相对大小随之改变。所以机位表必须**同时写焦距 + 距离或占画面比**，
单写一个锁不住透视。过肩镜的快捷判法：前景肩:对面孔的大小比——
广角近 1.5–2 倍，50mm 约 1.1–1.3 倍，长焦趋近 1。

**默认取 35mm 或 50mm 一个值贯穿全场**，只在机位表里对特写机位单独标注
（如 M7 用 85mm）。禁止每张图自由发挥焦距。

⚠️ **研究实锤**：直接文生图模型**无法**把「24mm vs 70mm」翻译成一致透视
（Generative Photography, arXiv:2412.02168）。所以焦距必须**参数 + 视觉效果
双写**；要求高时引导用户走草图定构图或带相机参数控制的链路。
