# 完整范例 — 一场咖啡馆对话戏

从两张正反打图到 5 张多机位图的全过程。改 skill 或不确定输出长什么样时，
对照这个范例。

## 0. 输入

两张正反打图（虚构描述）：

- `A.jpg`：女 A 站在咖啡桌左侧，胸口以上，面朝画面右说话；前景右下有男 B
  的左肩后脑；背景右侧大窗、左侧书架；暖色顶光
- `B.jpg`：男 B 坐桌右，胸口以上，面朝画面左听；前景左下有女 A 的右肩；
  同背景；同光

## 1. analysis（Step 1 产物，节选）

```yaml
horizon:
  evidence: "窗框上沿与书架顶板延长线交汇于画面高度 40% 处"
  camera_height_m: 1.35
  tilt: 水平
focal_length:
  estimate: 35mm
  evidence: "过肩肩:头 ≈ 1.15:1，背景可见整面墙，边缘无拉伸"
axis:
  description: "A 站桌左，B 坐桌右，轴线水平横穿画面"
  camera_side: "轴线南侧（靠近镜头一侧）"
  base_setup: "M1 正打机位为 0° 基准"
  conflict: 无
eyelines:
  A: 面朝右，视线向右下 5°（B 坐着更低）
  B: 面朝左，视线向左上 5°
locked_props:
  - "红色水杯在 B 手边"
  - "右窗左书架"
uncertain: 无
```

## 2. 机位表（Step 2 产物，完整一行示例）

**M1 · 正打（过 B 肩拍 A）**

- 参数式：B 左后方 30°，沿轴线看 A；高度 1.35m；35mm；过 B 肩；中近景
- 画面式：画面右下 15% 是 B 的左肩后脑；A 占画面左 1/3、胸口以上、面朝右
  说话；视平线在画面高度约 40%；背景右侧大窗、左侧书架；桌面红色水杯在
  画面下缘偏右

（M2–M5 同格式，略。M3 总机位 1.5m/35mm 双人全景；M4 A 侧面 1.35m/50mm；
M5 特写 A 1.35m/85mm。全部在同一轴线侧。）

## 3. 生成提示词（M1，三明治结构）

```
【锁定块】咖啡馆场景，白天暖色光。红色水杯固定在桌面 B 手边。
背景结构固定：画面右侧大窗、左侧书架，位置不变。
视平线固定在画面高度约 40%，镜头轻微平视。
人物外观锁定：A 长发白衬衫站立，B 短发深色外套坐着。
以上锁定项所有输出不变。

【机位 M1·正打】35mm 视角，中近景。画面右下 15% 为 B 的左肩与后脑
（前景虚化）。A 占画面左 1/3，胸口以上入画，面朝画面右侧说话，
视线向画面右方略向下（看向坐着的 B）。

【画面块】A 正在说话，表情专注，右手轻扶桌面。桌上红色水杯在画面
下缘偏右。背景右侧窗透入日光，左侧书架虚化。

【禁止块】禁止：A 出现在画面右侧；禁止 A 面朝左；禁止翻转左右布局；
禁止改变水杯位置；禁止广角畸变或长焦压缩（保持 35mm 自然透视）。
```

## 4. 自检记录（Step 4 产物）

| 机位 | 抽卡 | 违例史 | 最终 |
|---|---|---|---|
| M3 总机位 | 2 | 第 1 张水杯跑到左边 → 局部重绘水杯区 | 通过 |
| M1 正打 | 1 | — | 通过 |
| M2 反打 | 3 | 第 1、2 张 A 肩膀前景变成了 B 自己的肩 → 修正句「前景必须是 A 的右肩」 | 通过 |
| M4 A 侧面 | 4 | 第 1 张越轴（B 跑到 A 后方错误侧）→ 机位块补「贴近轴线但不越过」 | 通过 |
| M5 特写 | 2 | 第 1 张视线看镜头 → 修正句「视线向画面右下」 | 通过 |

5 机位共抽 12 次。5 图并排核对：地平线高度一致、水杯位置一致、
左右关系一致 → 交付。

## 5. 范例的三个教训（对应 skill 的硬约束）

1. **M4 侧面机位最容易越轴**——贴轴线的机位要在画面式描述里写明
   「另一人物在画面的哪一侧」
2. **前景肩归属错误是最高发违例**——画面式描述里前景肩必须写清
   「属于谁、占画面多少、在哪个角」
3. **道具漂移用局部重绘最省**——整图重抽会引入新的违例
