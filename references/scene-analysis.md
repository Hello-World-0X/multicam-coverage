# 反推方法论 — 从正反打图读出相机参数

Step 1 的操作手册。目标：把两张正反打图翻译成**可核对的参数**，
输出 `analysis` 结构（见文末）。每条结论必须写出**依据**（看到什么→推出什么），
不允许凭感觉填数。

## 1. 找地平线（视平线）—— 一切高度的基准

地平线 = 画面中「无穷远处的水平线」= **相机高度**（相机水平时）。
正拍场景里人眼不一定在地平线上，但地平线一定可以通过平行线找到。

**找法**（按可靠性排序）：

1. **建筑平行线汇聚**：窗框上下沿、门框、桌面边缘、踢脚线、瓷砖缝——
   找两组以上水平方向的平行线，沿它们画延长线，交点连成的水平线即地平线
2. **窗外地平线/远景线**：直接可见时最可靠
3. **同一水平面上的等高点**：远处椅面、桌面、窗台的远端边缘点都在地平线附近
   收敛

**地平线落点判读**：

| 观察 | 结论 |
|---|---|
| 地平线穿过站立人物眼睛附近 | 平视，机位 ≈ 1.55–1.65m（人物眼高） |
| 地平线在人物胸部附近 | 平视，机位 ≈ 1.2–1.4m（坐姿对话常见） |
| 地平线在人物膝盖以下 / 画面可见天花板 | **仰拍**，机位低于视平 |
| 地平线在人物头顶以上 / 画面可见大片地面 | **俯拍**，机位高于视平 |
| 垂直墙线不平行、上端内收 | 相机有仰角，透视为**三点透视**，标注俯仰角 |

> ⚠️ 常见误判：人物**低头/抬头**会改变眼睛在画面中的位置，不改变地平线。
> 永远用建筑平行线定地平线，别用人眼位置定。

## 2. 定焦距（透视强度）—— 四条线索交叉验证

单图估焦距没有公式，但四条线索能收敛到一档：

| 线索 | 广角（≤28mm） | 标准（35–50mm） | 长焦（≥85mm） |
|---|---|---|---|
| a. 边缘拉伸 | 画面边缘物体/脸明显横向拉伸 | 轻微 | 无 |
| b. 近大远小 | 前景（过肩的肩）与人脸的尺寸比夸张 | 正常 | 前景与背景尺寸被压平 |
| c. 背景跨度 | 一间屋子纵深全收进来 | 中等 | 背景只见一小块、明显虚化 |
| d. 平行线夹角 | 灭点近，平行线夹角大 | 中 | 灭点远，近乎平行 |

**过肩图的快捷判法**：看前景肩膀与对方面孔的大小比。
肩显著大于头（近 1.5–2 倍）→ 广角；比值接近真实比例 → 标准；被压平 → 长焦。

**输出要求**：写成「35mm（依据：c 中等背景跨度 + b 尺寸比正常）」，
不能只写「标准镜头」。两张正反打图的焦距**应一致**，不一致时以更可信的一张为准并标注。

## 3. 定方位角与轴线

1. **画轴线**：连接两人（或两人视线投向点）在**俯视图**中的连线。
   从单张图推俯视位置的技巧：
   - 看两人相对大小 → 谁离机位近
   - 看两人重叠关系（遮挡）→ 谁在前
   - 看地面接触点在画面中的高低 → 低者近（平视/俯视时）
2. **判机位侧**：前景过肩者在画面左 → 机位在其右后方（反之亦然）
3. **判轴线侧**：正反打两张图的机位是否在轴线同侧？——
   同侧时两张图的屏幕方向互补（A 看右 / B 看左）；
   如果两张图里两人都看同一边，说明**素材本身就有一镜越轴**，立刻报告用户
   并让用户指定以哪张为准（后续所有机位锁在那一侧）。
4. **估方位角**：把正打机位当作 0° 基准（沿轴线看 B），
   反打机位记为「轴线对侧镜像位」。待补机位的角度都是相对这组基准描述。

## 4. 定遮挡与深度分层（透视错乱的隐藏元凶）

对每张参考图画出**深度层**：

```
前景层：过肩的肩膀/头部（占画面 %）
中景层：主体人物（占画面 %）
背景层：家具/门窗/墙（列出哪边有什么）
极远景：窗外/走廊尽头
```

记录**遮挡顺序**（谁挡住谁）。多机位图最常见的怪异感不是角度错，
是**遮挡顺序错**（本该被挡的道具跳到前面）。机位表里要有「前景层」列。

## 5. 视线与朝向（对话戏专用规则）

**eyeline matching（视线匹配）**：正反打两镜中，双方视线必须**指向对方在画面
中的假想位置**，且视线高度大致相当。

- A 的图里 A 看画面右 → B 的图里 B 应看画面左（互补）
- 两人看同一边 → 两人都在看画外第三者（合法，但要写进锚点）
- 视线看向镜头 → 除非是直视镜头设计，否则是生成缺陷

记录三件事：朝向（面朝哪）、视线（眼看哪）、视线高度（平视/俯视对方）。

## 6. 光照反推

- 阴影方向 → 主光方位（阴影指向 = 背光侧）
- 面部明暗分布 → 主光高度（顶光/平光/底光）
- 色温 → 暖（钨丝/夕阳）/ 冷（月光/日光灯）/ 中性
- 高光点位置（眼球、鼻梁）→ 光位的方位角与高度

## 7. `analysis` 输出结构（Step 1 的产物）

```yaml
analysis:
  source: [正打图文件名, 反打图文件名]
  horizon:
    evidence: "窗框上下沿延长线交汇于画面高度 42% 处"
    camera_height_m: 1.35
    tilt: 水平        # 或 仰 5° / 俯 10°
  focal_length:
    estimate: 35mm
    evidence: "过肩肩:头 ≈ 1.2:1，背景可见整面墙，边缘无明显拉伸"
  axis:
    description: "A(女) 站桌左，B(男) 坐桌右，轴线水平横穿画面"
    camera_side: "轴线南侧（A 的左后方一侧）"
    base_setup: "正打机位 = 0° 沿轴线看 B；反打 = 镜像位"
    conflict: 无       # 若素材有越轴，在此标注并等待用户裁决
  staging:            # 深度分层，逐图
    shot_A:
      fg: "B 的右肩，画面右下 15%"
      mg: "A 占画面左 1/3，胸口以上"
      bg: "右侧窗，左侧书架"
      occlusion: "B肩 遮挡 桌角 遮挡 墙"
      shot_size: 中近景
    shot_B: { ... }
  eyelines:
    A: 面朝右，视线向右下 5° 看坐着的 B
    B: 面朝左，视线向左上 5° 看站着的 A
  lighting:
    key: "左上方 45° 主光，暖色 3200K，阴影投向右下"
  locked_props:
    - "桌面红色水杯在 B 手边（画面中偏右）"
    - "背景右窗、左书架位置固定"
  uncertain:          # 本方法无法判定的，列出来问用户
    - "B 的具体坐姿（是否翘腿）看不清，待确认"
```

**禁止**：`uncertain` 非空时直接跳到 Step 3 生成。必须先问用户。
一个瞎猜的轴线或高度会污染整批图，返工成本远高于一次提问。
