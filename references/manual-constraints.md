# 人工约束标注 — 弱纹理区的干预入口

适用：反推时发现弱纹理（白墙/桌面/天花板）深度不可信，或用户要求更高几何精度。
核心思想：**弱纹理表面大多是平面，而平面是低维的——3 对对应点解一整面墙**。
这比「手动加纹理」高效：不是给每个像素加线索，是给低维结构解方程。

与 `scene-analysis.md` 的 uncertain 流程衔接：uncertain 从「只能提问」升级为
「提问 + 标注入口」。标注内容汇入同一个 `analysis`。

## 1. 约束菜单（能标的不止点）

| 标什么 | 给出什么信息 | 典型用途 |
|---|---|---|
| **点对** p↔p'（两图同一物理点） | 一个 3D 点（三角化） | 种子点、校验位姿 |
| **3+ 点对在同一平面** | **整个平面**的方程 → 平面所有像素深度 | 白墙、桌面、地板、天花板 |
| **线段对**（墙角/门框/桌沿） | 平面朝向 + 交线 | 轮廓约束，比点稳 |
| **矩形四角**（窗框/瓷砖/画框） | 平面 + 纵横两个方向 | 窗、地砖、挂画 |
| **深度提示**（「这点距相机 3.2m」） | 直接给绝对尺度 | 干掉尺度锚不确定性 |
| **灭点**（平行线汇聚点） | 相机朝向 + 平面方向 | 平行线多的场景一击致命 |

**曼哈顿世界先验**（室内免费）：墙/地板/天花板互相垂直且对齐重力。
标出「这条是墙地交线 + 这条是竖直墙角」，房间坐标系即锁定，其余平面自动对齐。

### 平面为什么 3 点就够

```
图1（过 B 肩拍 A）            图2（过 A 肩拍 B）
┌────────────┐              ┌────────────┐
│    白 墙    │              │    白 墙    │
│      •p1 ──────────────────────•p1'    │
│      •p2 ──────────────────────•p2'    │
│      •p3 ──────────────────────•p3'    │
└────────────┘              └────────────┘
        ↓ 每对点三角化 → 3 个 3D 点
        ↓ 3 个不共线点定一个平面（4 自由度）
   整面墙所有像素深度 = 平面方程代入 ✓
```

6 次点击 → 解一整面墙。这是「低维结构」的红利。

## 2. constraints.yaml 格式（与 camera_spec.yaml 并列）

```yaml
# constraints.yaml —— 人工/半自动标注
point_pairs:
  - {img1: [412, 230], img2: [388, 241], note: "墙纸接缝交点"}
  - {img1: [455, 228], img2: [430, 239]}
  - {img1: [430, 300], img2: [405, 312]}
planes:
  - name: back_wall
    from: point_pairs[0:3]
lines:
  - {img1: [[300,180],[300,420]], img2: [[280,190],[280,430]], note: "竖直墙角"}
depth_hints:
  - {img1: [200, 400], depth_m: 3.2, note: "门框到相机距离，现场量过"}
vanishing_points:
  - {lines: [0, 1], note: "墙面水平线组"}
```

## 3. 进管线的求解顺序

```
位姿初值（机位表 / SfM）
   ↓ + point_pairs / lines / planes
捆绑调整（bundle adjustment）：位姿与平面/点联合优化   ← 摄影测量标准做法
   ↓
带约束的深度场（弱纹理区由平面方程补全，不靠猜）
   ↓
反投影 → 渲染 → 补洞（照旧，见 geometric-pipeline / prompt-strategy）
```

**验收指标**（两条，随手可查）：

1. **重投影误差 < 1–2 像素**：约束点经「3D → 两图」回投后与标注位置的距离。
   超了 = 位姿错或标注错，排查后再往下走
2. **平面拟合残差正常**：约束点到拟合平面的距离异常大 → 该面不是平面、
   或标错了，退回 uncertain 流程

## 4. 半自动分工（agent 预标 + 人工确认）

标注本身不必纯人工：

1. agent 识别候选约束：「检测到一整面白墙 / 一个桌面 / 窗框四角」
2. agent 在两图上**预标对应点**——找接缝、污渍、开关面板这类微特征对视觉
   模型是容易题
3. **人做确认**（yes/no 或拖动微调）——人机分工，不是人手从零点
4. 拿不准的进 uncertain 问用户

这是 scene-analysis「反推」的强化版：反推是从像素**估**，标注是给人**干预**
的入口，两者汇入同一个 analysis。

## 5. 局限（哪些洞标了也没用）

| 局限 | 原因 | 对策 |
|---|---|---|
| **要求两图都看得见** | 对应点的本质约束。正反打两镜朝向相对、重叠区有限 | 只在单张图露出的面 → 仍归 hole_mask，交给生成 |
| 反射/透明面 | 「对应点」随视角变（镜面是虚像） | 整块当洞，别标 |
| 标注误差会传播 | 点错一个 → 平面歪 → 整墙歪 | 关键平面多标点做冗余，用残差把关 |
| 人工成本 | — | 只标关键处：恒定物所在平面、大面墙地、决定构图的面 |

⚠️ 与 multiview-geometry.md §5 信息边界的关系：
**标注解决「可见但测不准」，解决不了「根本没拍到」**。白墙两图可见 → 标点可解；
A 的后背两图都没拍 → 无从标起，仍是生成的活。洞掩码依然存在，只是变小了。

## 6. 历史注脚

这套流程 = **摄影测量 60 年的标准作业**：自动匹配（~80% 点）+ 人工控制点
（关键处）+ 捆绑调整（联合解）。深度学习强化了「自动匹配」那 80%，
弱纹理的 20% 硬骨头业界一直靠人工约束——航测埋地面控制点、
VFX 跟踪师手点 user tracks。本节只是把这个传统接进生成管线。

## 7. 术语

| 术语 | 英文 | 含义 |
|---|---|---|
| 对应点/控制点 | tie point / GCP | 两图中标出的同一物理点 |
| 捆绑调整 | bundle adjustment | 位姿与 3D 点联合优化 |
| 点提示深度 | point-prompted depth | 把标注点当 prompt 精修深度网络 |
| 曼哈顿世界 | Manhattan world | 室内三正交平面的场景先验 |
| 灭点 | vanishing point | 平行线在无穷远的汇聚点 |
