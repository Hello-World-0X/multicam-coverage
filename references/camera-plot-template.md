# 机位图模板（camera plot）

Step 2 的输出格式。照这个结构填，不要另起格式。
三个部分：**空间锚点块**（全局锁定）、**机位表**（双列描述）、**检查区**。

---

## 一、空间锚点块（全局锁定，每张生成图逐字复用）

```markdown
## 空间锚点（全局锁定）

- 场景：<一句话：地点 + 时段 + 谁在哪>
- 轴线：A ↔ B 连线，走向 <水平/斜向>。全部机位在轴线【哪一侧】。
- 屏幕方向（锁死）：A 面朝【右】看向 B；B 面朝【左】看向 A。
  任何机位下不得翻转此朝向关系。
- 地平线：约【X m】，视平线位于画面高度约【N%】，平视 / 仰 X° / 俯 X°
- 焦距基准：全场【35mm】（特写机位例外见机位表）
- 光照：主光【方向/高度】，色温【暖 3200K / 冷 / 中性】，阴影投向【】
- 恒定物（所有机位位置不变）：
  - 【红色水杯：桌面 B 手边】
  - 【背景右侧大窗、左侧书架】
```

## 二、机位表（每个机位两列描述）

**参数式** = 给人看 + 校验用；**画面式** = 塞进生成提示词用。
两列都必须写满，画面式禁止出现「约 45°」「稍微」这类模糊词。

| 编号 | 名称 | 参数式 | 画面式 | 越轴风险 | 预算 |
|---|---|---|---|---|---|
| M1 | 过 B 肩拍 A | B 外侧后方 30°（B 在机位与 A 之间），沿轴线看 A；1.35m；35mm；中近景 | 右下 15% 为 B 的左肩后脑（虚化）；A 占左 1/3 胸口以上、面朝右说话、视线右下；视平线约 40% 高；右窗左书架；水杯下缘偏右 | 低 | 2–3 |
| M2 | 过 A 肩拍 B | A 外侧后方 30°（A 在机位与 B 之间），沿轴线看 B；1.35m；35mm；中近景 | 左下 15% 为 A 的右肩（虚化）；B 占右 1/3 胸口以上、面朝左倾听、视线左上；同背景同水杯 | 低 | 2–3 |
| M3 | 总机位 | 顶角，双人中垂线外 2.5m；1.5m 略俯；35mm；双人中景 | A 左 B 右同框，桌面全貌、双人完整，背景窗/书架同侧，视平线约 35% | 低 | 2–3 |
| M4 | A 正侧面 | 贴轴线 A 正侧；1.35m；50mm；中景 | A 侧面剪影感、面朝画面右；**B 在画面右缘入画**（证明未越轴）；背景见窗 | **高** | 20 |
| M5 | A 特写 | 同侧推近至 A 面前 1.2m；1.35m；85mm；特写 | A 面部占 70%，视线向画面右下，背景窗虚化成光斑 | 中 | 3–5 |

**画面式的写法要领**（prompt-strategy §3）：
1. 先写**前景遮挡物**（属于谁、占多少、在哪个角）——前景肩归属是最高发违例
2. 写主体**在画面中的位置 + 朝向 + 视线**
3. 写**视平线高度百分比**——地平线漂移的直接解药
4. 写**恒定物在画面里的位置**
5. 焦距写两遍：参数一遍（35mm）+ 视觉效果一遍（「自然透视，肩头比例正常，
   无广角拉伸」）

## 三、检查区

```markdown
## 越轴检查

- [ ] 全部机位在同一侧（每张图 A 均在左 / B 均在右）
- [ ] 贴轴线机位（M4 类）画面里另一人物位置可证明未越轴
- [ ] 每个机位视线方向与空间锚点一致

## 生成计划

- 链路：<图生图+参考图 / 草图定构图 / ...>
- 参考图：统一用 <A.jpg / A.jpg+B.jpg>，生成图禁止互相喂
- 顺序：M3 → M1 → M2 → M4 → M5（锚点先行）
- 抽卡预算：合计约 <N> 次（按机位表预算列相加 × 1.5 余量）

## 待确认项（uncertain 非空则不得开始生成）

- 无 / <列出问题>
```

## 四、批量生成的输出约定

1. 文件名：`<场景>_M<N>_<机位简称>.png`，如 `咖啡馆_M1_OTS_B.png`
2. 每张生成后立即过自检清单，过了才下一张
3. 交付物 = 图片 + **自检记录表**：

| 机位 | 抽卡次数 | 违例史 | 最终手段 |
|---|---|---|---|
| M3 | 2 | 第 1 张水杯漂移 → 局部重绘 | 通过 |
| M1 | 1 | — | 通过 |
| ... | | | |

4. 全部完成后 5 图并排核对（地平线高度 / 恒定物 / 左右关系）再交付
