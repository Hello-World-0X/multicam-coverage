## 1. 这个 skill 解决什么问题

**场景**：手上有一场戏的正反打图（shot/reverse-shot，两人对话一正一反两镜），
要批量补出同一场戏的其他机位视角图。

**症状**：直接让 agent 生成时透视互相对不上——人物左右翻转、视线错乱、
地平线漂移、焦距忽广忽长、道具换位。

**根因**：图像模型**没有三维推理能力**，只是按描述统计性地铺像素。
每张图独立生成 = 每张独立抽卡，空间关系自然对不上。

**解法**（三层，缺一不可）：

1. **共享空间真相**——《机位图》(camera plot)：先从参考图反推参数，
   物化成可核对的结构化文本，所有生成都引用它
2. **视觉锚**——参考图链路 + 锚点先行顺序，不靠纯文字想象场景
3. **校验迭代**——每张图过 18 项自检，违例走修正协议（最小改动），
   而不是重抽碰运气

## 2. 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 对话戏（正反打）补多机位静态图 | 单张图的美学提升、修图 |
| 同一场景多角度批量出图 | 跨场景连续性（需角色表 + 场景表体系） |
| 图生图 / 参考图链路的空间一致性 | 视频分镜（用视频提示词类 skill，见 §8） |
| 任意图像模型（提示词格式与模型解耦） | 需要真实相机标定/三维重建精度的场合 |

## 4. 核心方法论（改动前必须理解）

这个 skill 不是「提示词写法合集」，是一条**收敛管线**：

```
参考图 → [反推] → analysis → [物化] → 机位图 → [锚点先行] → 逐机位生成
                                                     ↓
                            交付 ← 并排核对 ← [自检+修正迭代]
```

### 4.1 反推要给依据（scene-analysis.md）

每条参数结论必须写「看到什么→推出什么」。四条线索交叉验证焦距、
用建筑平行线找地平线（**不用人眼位置定**——低头抬头会骗人）。
`uncertain` 非空禁止生成：一个瞎猜的轴线污染整批图。

### 4.2 机位表写两列：参数式 + 画面式（template）

- **参数式**：方位角/高度/焦距——给人看、校验用
- **画面式**：前景遮挡物 + 主体位置朝向视线 + 视平线高度% + 恒定物位置——
  塞进生成提示词用

> ⚠️ 改动红线：不要把机位表简化成形容词，也不要只留参数式。
> 模型不懂「45°」，只懂「右下角有 B 的左肩」。两列都要满。

### 4.3 生成策略比知识条文更决定成败（prompt-strategy.md）

- **三明治提示词**：锁定块（逐字复用）→ 机位块 → 画面块 → 禁止块
- **「必须保持」优于「不要改变」**（否定句在扩散模型里效果弱）
- **描述画面结果，不描述相机运动**（模型不懂「相机左转 45°」）
- **焦距写两遍**：参数一遍 + 视觉效果一遍
- **锚点先行**：M3 总机位 → 正反打 → 其余；不同机位不并行盲出
- **修正协议**：最小改动（小违例局部重绘），整图重抽是最后手段

### 4.4 两条已确认的设计取舍

1. **焦距当几何参数而非风格词**——禁「电影感」，必须具体。牺牲随机惊喜感，
   换透视稳定
2. **生成图禁止互相喂图**——参考图永远回原始正反打图。牺牲信息量，
   防误差累积

### 4.5 其余不变的硬约束

- 180° 轴线第一铁律（用户要越轴则照做但提示后果）
- 地平线高度全局统一
- 锁定项恒定（人物/道具/布局/光照）

### 4.6 证据基础（research-notes.md）

每条核心策略都有出处，改方法前先看它：

- **经典剪辑体系**（Wikipedia + Bordwell《Film Art》+ Mascelli《Five C's》）：
  180° 规则原始定义、**合法越轴三手法**（弧形移机/缓冲镜/重建定位，用户要
  越轴镜头时必须配套给缓冲镜）、**30° 规则**（机位两两夹角 ≥30° 或景别跳档）、
  视线匹配正式规范（同焦距+同高度+同距离，画外演员等距反侧）、OTS 三层深度
- **图像模型研究**（arXiv 2023–2026）：模型无法把焦距参数翻译成一致透视、
  参数条件化超过提示词工程、隐空间没有「相机旋转」概念——
  这些是「焦距双写」「描述画面不描述运动」「校验迭代兜底」的依据
- **实测 FOV 数值表**（Angle of view 条目）+ 焦距-距离耦合规律

> ⭐ 越轴为何「怪」有实证解释：它损害**空间表征与物体位置记忆**（不影响
> 叙事理解）——所以违例图说不出哪里怪但就是不对。自检 A 组因此第一优先。

### 4.7 多视角几何（multiview-geometry.md）

管线设计的数学底座：一张图 = 一次投影 `x = K[R|t]X`；多视角 = 共享场景 X、
不同外参。视图间三层关系（对极几何 → 三角化 → 重投影）解释了为何「渲染
路线」几何级准确；**信息边界**（输入图的可见区 / 新机位才露出的未见区）
解释了为何无法纯流程化——未见区必须靠生成「编」，而那正是透视易崩处。
该文件末尾有「本 skill 各设计的数学出处」对照表，改管线前先看它。

### 4.8 人工约束标注（manual-constraints.md）

弱纹理区（白墙/桌面）深度猜不准时的干预入口：点对/线段/平面/深度提示。
关键洞察：**弱纹理面多是平面，3 对对应点解一整面墙**（低维结构红利）。
半自动分工：agent 预标对应点 → 人工确认 → 捆绑调整联合优化位姿与平面，
验收看重投影误差 <1–2px。局限：要求两图都可见（只在一图露出的面标了也
没用，仍归 hole_mask）；反射/透明面别标。这是摄影测量 60 年标准作业
（自动匹配 + 人工控制点 + 捆绑调整）接进生成管线。

### 4.9 几何管线（geometric-pipeline.md）——路线 A 的工具链方案

提示词路线（C）之外的升级路线：深度估计 → 反投影 → 新机位渲染 → **定向补洞**。
透视由数学保证，生成模型只在 hole_mask 里发挥。两个技巧：**尺度锚**（拿人
当尺子，把相对深度换算成机位表的米数）、**机位表当位姿源**（SfM 降级为
校验工具）。三个陷阱：掠射角并入洞、双图融合按深度方差合并、幻觉区留
provenance 痕迹。实现形态推荐「agent + API」（贴合现有链路、免 GPU）。
与 skill 零缝对接：只换 Step 3–4 的执行器，机位表/QC 照用。

## 6. 验证方法（改动后自测）

1. **准备**：一场戏正反打图 2 张
2. **跑管线**：走完 Step 1–5，产出 analysis + 机位图 + ≥4 机位的图 + 自检记录表
3. **对照验证**：
   - analysis 每条结论有依据？uncertain 有走提问？（方法论测试）
   - 机位表双列齐全、画面式无模糊词？（格式测试）
   - 每张图过 18 项，A 组（轴线方向）零违例？（正确性测试）
   - 并排看：地平线/焦距感/恒定物/左右关系一致？（一致性测试）
   - 抽卡次数与预算量级相符？（成本测试）
4. **回归**：故意要越轴机位 → 确认提示后果；故意给有越轴的参考图 →
   确认报告并要求裁决

## 7. 术语表（给非影视背景的改动者）

| 术语 | 英文 | 含义 |
|---|---|---|
| 正反打 | shot / reverse-shot | 对话戏交替拍两人：A 说话一镜、B 反应一镜 |
| 机位 | camera setup | 摄影机摆放位置与参数组合 |
| 轴线 | axis / line | 两人物连线。180° 规则：机位不许跨到线另一侧 |
| 越轴 | crossing the line | 机位跨到轴线另一侧，屏幕左右翻转，空间感断裂 |
| 三角机位法 | triangle system | 对话戏标准覆盖：正打+反打（底边）+ 总机位（顶角） |
| 总机位 | master shot | 双人同框交代空间关系的大景别 |
| 过肩 | over-the-shoulder (OTS) | 前景带肩膀的构图 |
| 景别 | shot size | 特写/近景/中景/全景等框取范围 |
| 屏幕方向 | screen direction | 人物在画面中的朝向/运动方向，跨镜须连贯 |
| 视线匹配 | eyeline matching | 正反打双方视线互指对方假想位置，高度相当 |
| 地平线/视平线 | horizon / eye level | 平行线汇聚的水平线 = 相机高度（水平时） |
| 灭点 | vanishing point | 平行透视线汇聚点，判断透视自洽用 |
| 深度分层 | depth layering | 前景/中景/背景的遮挡顺序，透视错乱的隐藏元凶 |
| 抽卡 | re-roll | 同一提示词多次生成选优 |

## 10. 已知限制

- **三人以上群戏**：只覆盖单轴对话戏（见 §5 扩展方向）
- **动态运镜/视频**：假设离散机位出静态图
- **精确几何**：产出「视觉自洽」的机位描述，非相机标定；真三维对齐走重建路线
- **模型能力上限**：部分模型对方位角理解有限。若反复越轴：换支持构图约束的
  模型，或改用相对变换表述（「以参考图机位向左转 45°」），或走草图定构图链路
- **反推精度**：单图估焦距/高度本质是估计值（四线索交叉验证可收敛到档位，
  但不是真值）；误差会传入机位表——所以分析要给依据、不确定要问人
